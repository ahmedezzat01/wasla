Wasla · وصلةمركز اشتراكاتك الذكي — تتبع، أدر، ووفر

Wasla is a senior Human-Computer Interaction (HCI) project from Umm Al-Qura University — College of Computing. It is a bilingual (Arabic-first, RTL) mobile app for tracking, managing, and saving on digital and physical subscriptions.

This page is the project's technical documentation. It includes brand guidelines, architecture, code highlights, research methodology, testing results, accessibility verification, and deployment notes — every claim is backed by either the project report or the running Flutter app.

The Problem

Before building anything, the team surveyed 221 young adults and professionals in Saudi Arabia and ran 6 in-depth interviews. The data is unambiguous: existing tools fail Saudi users in four concrete ways.

Pain pointStatWhat users said
Unexpected charges 50.7% Forgotten subscriptions silently renew and surprise users with bills they didn't anticipate.
No renewal reminders 96.9% Almost all users want timely renewal alerts — but no existing tool provides them out of the box.
Unaware of top costs 48% Nearly half of users can't tell which single subscription costs them the most.
Fragmented & not Arabic — Existing tools juggle multiple platforms with no unified view — and almost none support Arabic RTL.
Financial waste — Forgotten renewals silently drain monthly budgets across streaming, gym, software, and SaaS.
No cancellation guidance — Users don't know how to cancel subscriptions properly — apps hide the exit.

The Solution

Wasla provides a centralised, Arabic-first, accessible platform to manage every subscription in one place — with timely reminders and clear financial visibility.

track_changes

3 days before — by default

Smart reminders fire automatically before every renewal. The interval is configurable per subscription, but 3 days is the sweet spot the team settled on after GP1 testing.

Key Features

Eight core features, each with its own real Arabic name, icon, and design rationale.

1. Authentication · تسجيل الدخول

Email + password, Google and Apple sign-in. Encrypted at rest, OAuth 2.0, 2-step email verification for password reset.

2. Add Subscription · إضافة اشتراك

Manual entry of category, price, billing cycle, dates, reminder settings, contact info for the cancellation guide.

3. Edit & Delete · تعديل / حذف

Update or remove subscriptions anytime with confirmation dialogs and a soft-delete grace period.

4. Dashboard · لوحة التحكم

Visual spending insights: monthly, yearly, average, count, plus a live chart with a Monthly / Yearly toggle.

5. Smart Offers · العروض الذكية

Personalised deals: Netflix 15% off, Fitness Time 10% off annual plan. Value without dark patterns.

6. Notifications · التنبيهات

Timely renewal and spending alerts, configurable per subscription, sent through Firebase Cloud Messaging.

7. Smart Chatbot · المساعد الذكي

Deterministic Arabic assistant: add, cancel, configure notifications, contact support — all from the chat.

8. Settings · الإعدادات

Language (AR/EN), dark / light mode, font size (small / medium / large), notification preferences.

Architecture & Actors

The system is built around three core actors, each with a clear responsibility split.

person

User Actor

Manages subscriptions (CRUD), views dashboard, receives reminders, talks to the chatbot, customises settings, views offers and cancellation guides, contacts support.

admin_panel_settings

Admin Actor

Manages advertisements, manages promotional offers, sends notifications, views system analytics.

memory

System Actor

Monitors renewal dates, generates automated notifications, processes spending analytics, stores preferences locally, re-renders all screens when mode changes.

Data Model

The core Subscription model is intentionally small and serialisable to Firestore. It captures every field the UI needs to render a card, a detail screen, and a cancellation guide.

lib/models/subscription_model.dart 
class Subscription {
  final String id;
  final String name;
  final String category;        // تنفليكس / شاهد / فيتنس
  final double cost;
  final String billingCycle;    // شهري / سنوي
  final DateTime startDate;
  final DateTime renewalDate;
  final int reminderDays;    // default: 3
  final String? notes;
  final bool isActive;
  final String? contactInfo;   // for cancellation guide

  Subscription({
    required this.id,
    required this.name,
    required this.category,
    required this.cost,
    this.billingCycle = "شهري",
    required this.startDate,
    required this.renewalDate,
    this.reminderDays = 3,
    this.notes,
    this.isActive = true,
    this.contactInfo,
  });

  Map<String, dynamic> toJson() => {
    'id': id,
    'name': name,
    'category': category,
    'cost': cost,
    'billingCycle': billingCycle,
    'startDate': startDate.toIso8601String(),
    'renewalDate': renewalDate.toIso8601String(),
    'reminderDays': reminderDays,
    'notes': notes,
    'isActive': isActive,
    'contactInfo': contactInfo,
  };
}

Code Highlights

Three representative snippets that show the project's idioms.

1. Dashboard spending chart

A single widget that toggles between monthly and yearly spending with a gradient header.

lib/widgets/analytics_chart.dart 
class SpendingChart extends StatelessWidget {
  final List<Subscription> subscriptions;
  final bool isMonthly;   // toggle from dashboard

  const SpendingChart({super.key, required this.subscriptions, required this.isMonthly});

  @override
  Widget build(BuildContext context) {
    final total = isMonthly
      ? subscriptions.where((s) => s.isActive)
          .fold<double>(0, (sum, s) => sum + s.cost)
      : subscriptions.where((s) => s.isActive)
          .fold<double>(0, (sum, s) => sum + s.cost * 12);

    return Container(
      padding: const EdgeInsets.all(20),
      decoration: BoxDecoration(
        gradient: const LinearGradient(
          colors: [Color(0xFF420691), Color(0xFF56369c)],
          begin: Alignment.topLeft, end: Alignment.bottomRight,
        ),
        borderRadius: BorderRadius.circular(22),
      ),
      child: Column(
        crossAxisAlignment: CrossAxisAlignment.start,
        children: [
          Text(isMonthly ? 'الإنفاق الشهري' : 'الإنفاق السنوي',
            style: const TextStyle(color: Colors.white70, fontSize: 14)),
          const SizedBox(height: 8),
          Text('${total.toStringAsFixed(2)} ر.س',
            style: const TextStyle(color: Colors.white, fontSize: 32, fontWeight: FontWeight.bold)),
        ],
      ),
    );
  }
}

2. Chatbot service — deterministic retrieval

The chatbot is not generative. Every response is a curated Arabic string from a hand-written map — no hallucination risk.

lib/services/chatbot_service.dart 
class ChatbotService {
  static final Map<String, String> _responses = {
    'كيفية إضافة اشتراك':
      '1. اضغط زر +\n'
      '2. اختر فئة الاشتراك\n'
      '3. أدخل السعر وتاريخ البدء\n'
      '4. حدد موعد التذكير\n'
      '5. اضغط حفظ',
    'كيفية إلغاء اشتراك':
      '1. افتح تفاصيل الاشتراك\n'
      '2. اضغط "تعليمات الإلغاء"\n'
      '3. اتبع الخطوات على الموقع الرسمي\n'
      '⚠️ حذف الاشتراك من التطبيق لا يلغيه فعلياً!',
    'إعدادات التنبيهات':
      'الملف الشخصي → إعدادات الإشعارات\nحدد عدد الأيام قبل التجديد',
    'التواصل مع الدعم':
      '• واتساب\n• البريد الإلكتروني\n• اتصال هاتفي',

  static String getResponse(String query) {
    for (final e in _responses.entries) {
      if (query.contains(e.key)) return e.value;
    }
    return 'عذراً، لم أفهم سؤالك. جرب:\n• كيفية إضافة اشتراك\n• كيفية إلغاء اشتراك\n• إعدادات التنبيهات\n• التواصل مع الدعم';
  }
}

3. Provider — reactive subscription list

lib/providers/subscription_provider.dart 
class SubscriptionProvider extends ChangeNotifier {
  final List<Subscription> _items = [];
  List<Subscription> get items => List.unmodifiable(_items);

  double get monthlyTotal =>
    _items.where((s) => s.isActive).fold(0, (sum, s) => sum + s.cost);

  double get yearlyTotal => monthlyTotal * 12;

  Future<void> add(Subscription s) async {
    _items.add(s);
    await FirebaseService.saveSubscription(s);
    notifyListeners();
  }

  Future<void> remove(String id) async {
    _items.removeWhere((s) => s.id == id);
    await FirebaseService.deleteSubscription(id);
    notifyListeners();
  }
}

Research Method

Wasla is a research-driven project. Every feature is grounded in user data.

221
Survey Participants
6
In-depth Interviews
5
Usability Test Users

Participants were recruited through university mailing lists, social media, and snowball sampling. The instrument combined Likert-scale items, ranking questions, and three open-ended prompts about subscription pain points.

Usability testing used the Think Aloud method with 5 active users on a build of the app. Each session lasted ~25 minutes, was recorded, and transcribed for thematic analysis.

Accessibility & Inclusivity (WCAG 2.1)

verified

WCAG 2.1 AA & AAA — All pass

Contrast ratios verified with the WebAIM contrast checker against the Wasla palette: 19.41 (normal text on white), 11.56 (large text on purple), 15.42 (light tint on dark), 12.57 (orange on white). The minimum AA threshold is 4.5:1 — Wasla clears it by 3× to 4×.

  • Arabic & English with native RTL / LTR layout.
  • Dark / Light mode with high contrast verified.
  • Font size customisation in 3 sizes: small / medium / large.
  • Icon + text navigation everywhere — never icon-only.
  • Screen reader support via Flutter Semantics.
  • Touch targets ≥ 48dp as per Material guidelines.

Ethical design highlights

policy

Anti-dark-patterns

Cancellation guidance is never hidden. The app explicitly warns that deleting a subscription from the app does not cancel it with the provider. No countdown timers, no manipulative ad placements.

lock

Data privacy

2-step email verification on password reset, OAuth 2.0 for social sign-in, encrypted HTTPS in transit, Firestore security rules limiting reads to the document owner.

smart_toy

AI bias risk

The chatbot is deterministic retrieval over curated Arabic responses — no LLM, no hallucination, no bias propagation. The assistant is labeled "متصل الآن" (connected now) to avoid impersonating a human.

check_circle

Conclusion

Wasla offers a practical solution for managing subscriptions, helping users track their subscriptions and avoid unwanted automatic renewals. The app addresses a real pain point in the Saudi / GCC market where subscription management tools lack Arabic support and localised features.
