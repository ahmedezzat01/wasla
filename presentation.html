One hub. Every subscription. Zero surprise charges.

05 · ARCHITECTURE · المعمارية

Clean Dart + Firebase. Three actors, one model.

The Subscription model is the heart. The Dashboard widget reads it. The Chatbot service answers questions about it. Real code from lib/models/subscription_model.dart on the left.

lib/models/subscription_model.dart 
// Real Subscription model from waslaa app
import 'package:cloud_firestore/cloud_firestore.dart';
import 'package:flutter/material.dart';

class Subscription {
  final String id;
  final String userId;
  final String name;
  final String? customName;
  final double price;
  final DateTime renewalDate;
  final DateTime? expiryDate;
  final String iconColor;
  final String? notes;
  final String? reminder;
  final String? contactInfo;

  late Color _cachedColor;

  Subscription({
    required this.id,
    required this.userId,
    required this.name,
    this.customName,
    required this.price,
    required this.renewalDate,
    this.expiryDate,
    required this.iconColor,
    this.notes,
    this.reminder,
    this.contactInfo,
  }) {
    _cachedColor = Color(int.parse(iconColor));
  }

  Color get color => _cachedColor;

  String get displayName {
    if (name == 'اشتراك مخصص' && customName != null) {
      return customName!;
    }
    return name;
  }

  Map<String, dynamic> toMap() {
    return {
      'userId': userId,
      'name': name,
      'price': price,
      'renewalDate': Timestamp.fromDate(renewalDate),
      'iconColor': iconColor,
    };
  }
}

06 · RESEARCH METHODOLOGY · منهجية البحث

Mixed-methods research, two GPs, 226 participants.

A multi-stage user-centred design process that informs every design decision in Wasla — from problem framing to final validation.

1
Literature & Market Review

Analysed 12 popular subscription apps to identify feature gaps in the GCC market.

2
Quantitative Survey · 221 participants

Online questionnaire targeting young adults (18–35) in Saudi Arabia — covered reminders, RTL, cancellation behaviour.

3
Qualitative Interviews · 5 users

Semi-structured interviews to deepen findings from the survey and uncover pain points around renewal tracking.

4
Think-Aloud Usability Test · 5 users

Conducted during GP1 and GP2 to validate prototypes and the final system, capturing confusion in real time.

07 · TESTING METHOD · طريقة الاختبار

Think-Aloud usability testing, twice.

A formative usability test with 5 participants during both GP1 and GP2. Participants performed real tasks while verbalising thoughts, confusion, and feedback.

1
Add a new subscription

From launch, through category selection, to saving.

2
Edit an existing subscription

Modify reminder settings, price, or notes.

3
Delete a subscription

Including the confirmation flow and feedback.

4
Manually add a custom subscription

Including contact info and notes fields.

5
Display the control panel

Open the dashboard and inspect monthly / yearly view.

Test Setup

  • Test name: Usability test for Wasla application
  • Test type: Usability Testing, Think-Aloud Protocol
  • Sample size: 5 users per round (GP1 + GP2)
  • Environment: Mobile (Android), touch-based
  • Prerequisites: Logged in, internet, ≥1 existing sub, notifications enabled
  • Data captured: time-on-task, error count, verbal protocol, post-task survey
  • Iteration cycle: find issues → fix in GP2 → re-test → ship
08 · TESTING RESULTS · نتائج الاختبار

GP1 → GP2: measurable improvement on every aspect.

A side-by-side comparison of GP1 (prototype) versus GP2 (final system) across the same six usability aspects.

Aspect GP1 Prototype GP2 System Improvement Status
Add Subscription Add button small & unclear, up to 55s to complete. Most users added subs successfully. Improved button visibility and easier navigation. Pass
User Interface Small fonts, unclear layout, unnecessary dashboard elements. Dashboard appreciated — clear and organized. Better UI organization and dashboard presentation. Pass
Reminder Editing Feature not available in GP1 testing. Most users successfully edited reminders. Added reminder editing with acceptable usability. Pass
Delete / Cancel Process simple, but no direct unsubscribe links. Most users deleted subs; some felt confirmations were excessive. Improved deletion flow and user guidance. Pass
Subscription Info Some users confused about expiry & renewal tracking. Dashboard clearly shows monthly & yearly expenses. Improved clarity of subscription tracking. Pass
Custom Subscription Feature not available in GP1 prototype. Users could manually add custom subscriptions. More flexible subscription management. Pass
